# Specification: Vivado PPA Data Extraction Script

## Objective
Write a Python script (`scripts/parse_ppa.py`) that reads the text reports generated by Vivado, extracts key metrics using regular expressions, calculates Throughput and Energy per Hash, and appends the results to a master `ppa_results.csv` file.

## Inputs (Command Line Arguments)
* `--report_dir`: Path to the directory containing the Vivado `.rpt` files.
* `--version_name`: Name of the architecture (e.g., `v1_baseline`).
* `--cycles_per_block`: Clock cycles required to process one 512-bit block (e.g., 65).
* `--target_period_ns`: The clock constraint applied during synthesis (e.g., 10.0).

## Metric Extraction Targets
* **Timing (`post_synth_timing.rpt`):** Find the Worst Negative Slack (WNS).
  * *Calculation:* $F_{max} = \frac{1}{\text{target\_period\_ns} - \text{WNS}}$ (in GHz). 
  * *Throughput:* $\frac{512 \times (F_{max} \times 10^9)}{\text{cycles\_per\_block} \times 10^6}$ (in Mbps).
* **Power (`post_synth_power.rpt`):** Find "Total On-Chip Power (W)".
  * *Energy per Hash:* $\frac{\text{Total Power} \times \text{cycles\_per\_block}}{F_{max} \times 10^9}$ (convert to nanojoules, $nJ$).
* **Area (`post_synth_utilization.rpt`):** Find "Slice LUTs" and "Slice Registers" (or "FFs") used.

## Output Structure
Append a row to `ppa_results.csv` with the following columns:
`Version | LUTs | FFs | WNS (ns) | Fmax (MHz) | Total Power (W) | Throughput (Mbps) | Energy/Hash (nJ)`
